## Artificial Intelligence
- **AI Agent**: an AI system that plans and takes multi-step actions with tools to complete a goal
    - **Agentic Browser**: a web browser with a built-in AI agent that can navigate and act on pages for you
    - **Agentic Workflow**: a fixed sequence of LLM and tool steps where code, not the model, controls the flow
    - **AI Coding Agent**: an AI agent that plans, writes, tests, and submits code changes with limited supervision
    - **MCP (Model Context Protocol)**: an open standard for connecting AI models to external tools and data sources
    - **Multi-Agent Orchestration**: coordinating several specialized AI agents that divide and hand off work
    - **Tool Calling**: a model requesting a function with structured arguments, which code then runs
- **AI Alignment**: making AI systems behave according to human intentions and values
- **AI Coding Assistant**: an editor plugin that suggests and completes code using AI
- **AI Guardrails**: limits on what an AI system may do or say, like allowed tools, step caps, or output checks
- **AI Research Assistant**: an AI tool that searches, reads, and summarizes sources to answer questions
- **AI Tutor**: an AI tool that adapts explanations and practice to help a learner understand material
- **Audio Analysis**: teaching computers to interpret sound such as speech, music, or environmental noise
    - **MFCC (Mel-Frequency Cepstral Coefficients)**: compact features that summarize a sound's spectrum
    - **Spectrogram**: a picture of how a sound's frequencies change over time
        - **Mel Spectrogram**: a spectrogram rescaled to the Mel scale to match how humans hear pitch
    - **Speech Recognition**: converting spoken audio into text
- **Computer Vision**: teaching computers to interpret and understand images and video
    - **Image Classification**: assigning one label to a whole image, such as "cat" or "truck"
    - **Image Segmentation**: splitting an image into regions to separate objects from the background
        - **Instance Segmentation**: also separates individual objects of the same class
        - **Semantic Segmentation**: labels every pixel with a class
    - **NeRF (Neural Radiance Fields)**: neural networks that reconstruct 3D scenes from a set of 2D images
    - **Object Detection**: finding and labeling objects in an image with bounding boxes
        - **Anchor Box**: a preset box shape a detector adjusts to fit each object
        - **IoU (Intersection over Union)**: how much a predicted box overlaps the true one
        - **mAP (Mean Average Precision)**: the standard accuracy score for object detectors
        - **NMS (Non-Maximum Suppression)**: drops overlapping boxes, keeping the most confident one
        - **R-CNN (Region-Based CNN)**: proposes candidate regions, then classifies each with a CNN
        - **YOLO (You Only Look Once)**: a fast detector that finds all objects in one pass
    - **OCR (Optical Character Recognition)**: converting images of text into machine-readable text
    - **Pose Estimation**: detecting body keypoints like joints to infer a person's pose
    - **Super-Resolution**: rebuilding a high-resolution image from a low-resolution one
- **Deepfake**: synthetic media that swaps or fabricates a person's face or voice using AI
- **Generative AI**: AI that creates new text, images, audio, video, or code from prompts
    - **AI Image Generation**: creating or editing images from text prompts
        - **Diffusion Model**: a generative model that creates images by learning to reverse a gradual noising process
    - **AI Music Generation**: creating songs, vocals, or background music from prompts
    - **AI Video Generation**: creating video clips or films from text, image, or video prompts
    - **AI Voice Generation**: synthesizing lifelike speech or cloning voices from text
- **LLM (Large Language Model)**: a neural network trained on huge text corpora to understand and generate language
    - **AI Chatbot**: a conversational interface for chatting with an LLM
    - **Distillation**: training a smaller student model to imitate the outputs or behavior of a larger teacher model
    - **Hallucination**: when a model confidently states false or made-up information
    - **Inference**: running a trained model to generate predictions or outputs
        - **Local LLM Inference**: running a language model on your own hardware instead of through a hosted API
    - **LLM Evaluation**: measuring model quality, accuracy, latency, and safety with repeatable tests
    - **LLM Framework**: a library for building apps that chain LLM calls, tools, and data sources
    - **Open-Weight Model**: a model whose trained weights are publicly released for anyone to run or fine-tune
    - **Pretraining**: training a model from scratch on a large unlabeled corpus
- **Model Hub**: a platform for sharing and downloading pretrained models, datasets, and demos
- **Multimodal Model**: a model that handles more than one type of data, such as images and text
- **NLP (Natural Language Processing)**: teaching computers to understand, process, and generate human language
    - **Bag of Words**: represents text by its word counts, ignoring word order
    - **Lemmatization**: reducing words to their dictionary form, e.g. "better" → "good"
    - **N-gram**: a sequence of n consecutive words, like a bigram or trigram
    - **NER (Named Entity Recognition)**: labeling people, places, and organizations in text
    - **POS Tagging (Part-of-Speech Tagging)**: labeling each word as a noun, verb, adjective, etc.
    - **Sentiment Analysis**: classifying text as positive, negative, or neutral
    - **Stemming**: chopping suffixes off words to get a crude root, e.g. "running" → "run"
    - **Stop Words**: common words like "the" and "is" that are often removed before analysis
    - **TF-IDF (Term Frequency–Inverse Document Frequency)**: weights words common in a document but rare overall
    - **Tokenization**: splitting text into units such as words, subwords, or sentences
    - **Word2Vec**: learns word embeddings from the words around each word, using CBOW or skip-gram
- **Prompt Engineering**: designing and refining model inputs to get accurate, useful outputs
- **RAG (Retrieval-Augmented Generation)**: improving LLM answers by retrieving relevant documents and adding them to the prompt
    - **Chunking**: splitting documents into smaller passages before embedding them for retrieval
    - **Re-Ranking**: reordering retrieved passages with a stronger model so the best come first
    - **Vector Database**: a database that stores embeddings and quickly finds those nearest a query
    - **Vector Embedding**: a numeric vector that represents the meaning of text, images, or other data
        - **Cosine Similarity**: measures how alike two vectors are by the angle between them

## Big Data
- **Data Lakehouse**: combines a data lake's cheap, flexible storage with a warehouse's structured querying
- **Data Warehouse**: a central repository optimized for analytical queries over large structured datasets
- **Distributed Computing**: splitting data storage and processing across a cluster of machines
    - **MapReduce**: a programming model that processes large datasets in parallel map and reduce steps
- **Distributed Key-Value Store**: a database spread across machines that stores data as sorted key-value pairs
- **Full-Text Search**: indexing text so documents can be searched by words and ranked by relevance

## Business Analytics
- **BI (Business Intelligence)**: turning business data into dashboards and reports that inform decisions
- **Business Model Canvas**: a one-page template for mapping a business's value proposition, customers, channels, and costs
- **Market Research**: gathering and analyzing information about markets, competitors, and customers
- **Spreadsheet**: a grid-based app for organizing, calculating, and charting data

## Data Analytics
- **Observability**: monitoring systems through metrics, logs, and traces to understand their health and performance
- **Web Analytics**: measuring and reporting website traffic, user behavior, and marketing performance
    - **Tracking Pixel**: a snippet on a website that reports visitor actions to an ad platform to measure and optimize ads

## Data Science
- **Computational Notebook**: an interactive document that mixes live code, output, charts, and notes
- **Data App**: an interactive web app that lets users explore data or models
- **Data Cleaning**: fixing incorrect, corrupted, duplicate, or incomplete data
    - **Imputation**: filling in missing values with estimates such as the mean or median
    - **Outlier Detection**: finding data points that differ sharply from the rest of the data
        - **IQR Method**: flags points more than 1.5 IQRs below Q1 or above Q3
- **Data Integration**: combining data from different sources into one unified dataset
    - **API (Application Programming Interface)**: lets programs request data or services from each other
        - **REST API**: an API that exposes resources at URLs and acts on them with HTTP methods
    - **JSON (JavaScript Object Notation)**: a text format of nested key-value data, the usual format of web API responses
    - **SQL (Structured Query Language)**: the standard language for querying and managing relational databases
- **Data Mining**: extracting and discovering patterns in large datasets
- **Data Preprocessing**: transforming raw data into a clean, consistent format for analysis or modeling
    - **Data Reshaping**: converting tables between wide and long form, e.g. by melting or pivoting
    - **Tidy Data**: a layout where each row is one observation and each column is one variable
- **Data Visualization**: representing data graphically with charts, plots, and interactive dashboards
- **EDA (Exploratory Data Analysis)**: summarizing and plotting a dataset to spot patterns, outliers, and problems before modeling
- **Regex (Regular Expression)**: a pattern language for searching, matching, and extracting text
- **Statistical Computing**: using programming languages and software to perform statistical analysis
- **Structured Data**: data in a fixed layout of rows and columns, like tables and spreadsheets
- **Unstructured Data**: data without a fixed table layout, like text, images, and audio
- **Vectorization**: applying an operation to a whole array or column at once instead of looping
- **Web Scraping**: automatically extracting data from websites

## IoT (Internet of Things)
- **Digital Twin**: a virtual model of a physical system kept in sync with its real-time data
- **IIoT (Industrial Internet of Things)**: connected sensors and machines in factories, plants, and other industry
- **MQTT (Message Queuing Telemetry Transport)**: a lightweight publish-subscribe messaging protocol for devices
    - **MQTT Broker**: the server that receives published messages and routes them to subscribers
- **PID (Proportional-Integral-Derivative) Controller**: a feedback controller that steers a system toward a setpoint

## Machine Learning
- **AutoML (Automated Machine Learning)**: automating model selection, feature engineering, and hyperparameter tuning
- **Benchmark Dataset**: a standard public dataset used to train, test, and compare models
- **Bias-Variance Tradeoff**: the balance between underfitting (high bias) and overfitting (high variance)
    - **Overfitting**: when a model memorizes its training data and fails on new data
    - **Underfitting**: when a model is too simple to capture the patterns in its data
- **Class Imbalance**: when one class far outnumbers the others, biasing a classifier toward it
    - **SMOTE (Synthetic Minority Over-sampling Technique)**: creates synthetic minority-class examples
- **Data Augmentation**: enlarging a training set with altered copies, like flipped images or reworded text
- **Deep Learning**: machine learning with multi-layer neural networks that learn features directly from data
    - **FLOPs (Floating-Point Operations)**: counts the arithmetic a model needs, a standard measure of compute cost
    - **Model Compression**: shrinking a model's size or compute while keeping accuracy
        - **Weight Pruning**: removing low-importance weights from a network to make it smaller and faster
    - **Neural Network**: layers of connected nodes, loosely inspired by the brain, that learn patterns from data
        - **Activation Function**: adds non-linearity to a neuron's output, e.g. ReLU or sigmoid
            - **ReLU (Rectified Linear Unit)**: outputs the input if positive and zero otherwise
            - **Softmax**: turns a layer's outputs into class probabilities that sum to 1
        - **Autoencoder**: a network that learns to compress and rebuild its input, often to spot anomalies
            - **Denoising Autoencoder**: learns to rebuild clean inputs from corrupted ones
        - **Backpropagation**: computing error gradients layer by layer to update a neural network's weights
            - **Automatic Differentiation**: computing exact derivatives of code automatically, as PyTorch does
            - **Exploding Gradient**: when gradients grow uncontrollably through layers, destabilizing training
            - **Vanishing Gradient**: when gradients shrink through many layers or time steps so early ones stop learning
        - **Batch Normalization**: normalizes layer inputs over each mini-batch to stabilize and speed up training
        - **CNN (Convolutional Neural Network)**: a neural network that uses convolution filters to learn spatial patterns in images
            - **AlexNet**: the 2012 ImageNet-winning CNN that launched the deep learning boom
            - **DenseNet**: a CNN that connects each layer to every later layer
            - **GoogLeNet (Inception)**: a CNN that runs several filter sizes in parallel inside each block
            - **LeNet**: LeCun's early CNN for handwritten digit recognition
            - **MobileNet**: a lightweight CNN built on depthwise separable convolutions for phones
            - **Pooling**: downsampling feature maps by keeping the max or average of each region
            - **ResNet (Residual Network)**: a CNN with skip connections that make very deep networks trainable
            - **Transposed Convolution**: upsamples feature maps with a learned convolution (deconvolution)
            - **U-Net**: an encoder-decoder CNN with skip connections, built for image segmentation
            - **VGG (Visual Geometry Group Network)**: a simple, deep CNN widely used as a pretrained backbone
        - **Encoder-Decoder**: compresses input into a representation, then expands it into an output
            - **Seq2Seq (Sequence-to-Sequence)**: maps an input sequence to an output sequence, like translation
                - **Autoregressive Decoding**: generating one token at a time, each based on the ones before it
                - **Beam Search**: keeps the top few partial outputs at each step instead of only the best
                - **Teacher Forcing**: feeding the true previous token during training instead of the model's guess
        - **GAN (Generative Adversarial Network)**: a generator and discriminator trained against each other
            - **Conditional GAN**: a GAN given extra input, like a label or image, to control what it generates
            - **Mode Collapse**: when a GAN's generator produces only a few kinds of outputs
        - **Layer Normalization**: normalizes across one example's features, standard in transformers
        - **MLP (Multilayer Perceptron)**: a feedforward network of stacked fully connected layers
        - **Perceptron**: a single artificial neuron that learns a linear decision boundary
        - **PINN (Physics-Informed Neural Network)**: a network whose loss also enforces known physics equations
        - **RNN (Recurrent Neural Network)**: a neural network with loops that processes sequences like text or time series
            - **LSTM (Long Short-Term Memory)**: an RNN with gated memory cells for long-range patterns
        - **Transformer**: a neural network architecture built on self-attention that underpins modern LLMs
            - **Attention Mechanism**: lets each token weigh how relevant every other token is to it
                - **Cross-Attention**: lets a decoder attend to the encoder's outputs
                - **Masked Self-Attention**: hides future tokens so a decoder only looks backward
                - **Multi-Head Attention**: runs several attentions in parallel to catch different relationships
            - **BERT (Bidirectional Encoder Representations from Transformers)**: encoder-only transformer pretrained on masked words
            - **Positional Encoding**: adds word-order information, since attention alone ignores order
            - **ViT (Vision Transformer)**: a transformer that classifies images by treating patches as tokens
        - **Universal Approximation Theorem**: one hidden layer with enough neurons can approximate any continuous function
        - **Weight Initialization**: choosing starting weights so signals don't vanish or explode, e.g. Xavier or Kaiming
    - **Representation Learning**: learning useful features from data instead of hand-designing them
    - **Tensor**: a multi-dimensional array, the core data structure of deep learning frameworks
- **Ensemble Learning**: combining multiple models to get better predictions than any single one
    - **Bagging**: trains models on random subsets of the data and averages their predictions
        - **Random Forest**: an ensemble of decision trees trained with bagging on random subsets of features
    - **Boosting**: trains models sequentially, with each one correcting the errors of the last
        - **AdaBoost**: a boosting method that reweights misclassified examples so later models focus on them
        - **Gradient Boosting**: a boosting method that fits each new tree to the remaining errors of the ensemble
- **Evolutionary Computation**: optimization methods inspired by natural selection and evolution
    - **Genetic Algorithm**: evolves candidate solutions through selection, crossover, and mutation
- **Feature Engineering**: creating, transforming, or selecting input variables to help a model learn
    - **Categorical Encoding**: converting categories into numbers, e.g. one-hot or label encoding
    - **Feature Scaling**: rescaling features to a common range so no single feature dominates
    - **Feature Selection**: keeping only the features that help a model and dropping redundant ones
- **Gradient Descent**: an optimization method that iteratively adjusts parameters in the direction that reduces error
    - **AdaGrad**: shrinks each weight's learning rate based on its past gradients
    - **Adam (Adaptive Moment Estimation)**: gradient descent that adapts each parameter's learning rate
    - **Epoch**: one full pass of the training data through a model
    - **Learning Rate**: the step size gradient descent takes on each update
        - **Learning Rate Schedule**: lowers the learning rate during training, e.g. step or exponential decay
    - **Momentum**: adds part of the previous update so steps keep a steady direction
    - **RMSProp**: scales each weight's learning rate by a moving average of recent gradients
    - **SGD (Stochastic Gradient Descent)**: gradient descent that updates after each random example (or small batch)
- **Hyperparameter Tuning**: searching for the best settings fixed before training, like tree depth
    - **Grid Search**: trying every combination of values in a predefined hyperparameter grid
    - **Random Search**: tries random hyperparameter combinations instead of every one
- **Loss Function**: measures how far predictions are from the true values; training minimizes it
    - **Cross-Entropy Loss**: compares predicted class probabilities to true labels, standard for classification
- **ML Framework**: a library for building, training, and running machine learning models
- **ML Platform**: a managed cloud service for building, training, and deploying ML models
- **MLOps (Machine Learning Operations)**: practices for tracking, deploying, and monitoring machine learning models
    - **Experiment Tracking**: logging the parameters, metrics, and artifacts of training runs so they can be compared
    - **Model Deployment**: serving a trained model so apps and users can request predictions
        - **Model Serialization**: saving a trained model to a file so it can be reloaded later
- **Model Evaluation**: measuring how well a trained model performs on data it has not seen
    - **Classification Metrics**: accuracy, precision, recall, and F1 score built from the confusion matrix
    - **Confusion Matrix**: a table of predicted vs. actual classes behind accuracy, precision, and recall
    - **Cross-Validation**: rotating the held-out data across folds for a more reliable score
    - **Data Leakage**: when test or future information leaks into training and inflates scores
    - **Feature Importance**: how much each feature contributes to a model's predictions
    - **Learning Curve**: plots training and validation scores as data grows to spot a poor fit
    - **Regression Metrics**: MAE, RMSE, and R² measure how far numeric predictions are from true values
    - **Train-Test Split**: holding out data so a model is tested on examples it never trained on
    - **Validation Set**: held-out data used during training to tune settings and catch overfitting
- **Preprocessing Pipeline**: chaining data transformations so they are applied consistently in training and inference
- **Recommender System**: suggests items a user may like based on past behavior or similar users
- **Regularization**: penalizing model complexity to reduce overfitting
    - **Dropout**: randomly switching off neurons during training so none become over-relied on
    - **Early Stopping**: stops training once validation performance stops improving
    - **L1 Regularization (Lasso)**: adds the absolute value of weights as a penalty, which can shrink some weights to zero
    - **L2 Regularization (Ridge)**: adds the squared value of weights as a penalty, which keeps all weights small
- **Reinforcement Learning**: training an agent to take actions that maximize rewards through trial and error
    - **Actor-Critic**: pairs a policy network that picks actions with a value network that scores them
        - **PPO (Proximal Policy Optimization)**: an actor-critic method that keeps each policy update small
    - **AlphaZero**: DeepMind's self-play algorithm that mastered chess, shogi, and Go using tree search and neural networks
    - **Bellman Equation**: defines a state's value as its reward plus the discounted value of the next state
    - **Policy**: the strategy an RL agent uses to choose an action in each state
        - **Epsilon-Greedy Policy**: takes the best-known action but explores randomly with probability ε
    - **Q-Learning**: learns a table of how valuable each action is in each state
        - **DQN (Deep Q-Network)**: Q-learning that swaps the table for a neural network
            - **Experience Replay**: training on random batches of stored past transitions to stabilize learning
    - **RL Environment**: a simulated world that an RL agent observes, acts in, and gets rewards from
- **Supervised Learning**: training models on labeled data to predict outputs from inputs
    - **Decision Boundary**: the line or surface where a classifier switches from one class to another
    - **Decision Tree**: a model that predicts by splitting data on feature values in a tree of if-then rules
        - **Gini Impurity**: how mixed a node's classes are, used like entropy to pick splits
        - **Information Gain**: the drop in entropy from a split, used to pick the feature to split on
        - **Pruning**: trimming a tree's branches to reduce overfitting
    - **KNN (K-Nearest Neighbors)**: predicts from the labels of the closest data points
    - **Linear Regression**: fits a straight line or plane that predicts a numeric value from input features
        - **Multiple Linear Regression**: linear regression with more than one input feature
        - **Polynomial Regression**: regression that fits curved relationships using polynomial features
    - **Logistic Regression**: predicts the probability of a class using a logistic (sigmoid) function
    - **Naive Bayes Classifier**: a probabilistic classifier that applies Bayes' theorem assuming independent features
        - **Laplace Smoothing**: adds a small count to every category so unseen values don't zero out a probability
    - **SVM (Support Vector Machine)**: finds the boundary that separates classes with the widest margin
        - **Kernel**: a similarity function that lets an SVM draw non-linear boundaries
- **Transfer Learning**: reusing a model trained on one task as the starting point for another
    - **Feature Extraction**: freezing a pretrained model and training only a new output layer
    - **Fine-Tuning**: further training a pretrained model on task-specific data
        - **LoRA (Low-Rank Adaptation)**: a parameter-efficient fine-tuning method that trains small low-rank matrices
- **Unsupervised Learning**: finding patterns and structure in unlabeled data
    - **Anomaly Detection**: finding rare points or events that deviate from normal behavior
        - **Gaussian Anomaly Detection**: flags points that are unlikely under a Gaussian fit to normal data
        - **Isolation Forest**: isolates anomalies with random splits, since outliers need fewer splits
    - **Association Rule Mining**: finding if-then rules between items that often occur together
        - **Apriori**: finds frequent itemsets to build association rules, as in market basket analysis
    - **Clustering**: grouping similar data points together without predefined labels
        - **DBSCAN**: density-based clustering that labels points in sparse regions as noise
        - **Elbow Method**: picking k where adding more clusters stops reducing error much
        - **Hierarchical Clustering**: builds a tree of nested clusters by repeatedly merging or splitting groups
        - **K-Means**: partitions data into k clusters by assigning points to the nearest cluster center
        - **Silhouette Score**: rates how well each point fits its own cluster versus the nearest other one
    - **Dimensionality Reduction**: shrinking the number of features while keeping most of the data's information
        - **PCA (Principal Component Analysis)**: reduces data dimensions by projecting onto the directions of greatest variance

## Mathematics
- **Calculus**: the mathematics of continuous change through derivatives and integrals
    - **Differential Calculus**: studies rates of change and slopes of curves through derivatives
    - **Integral Calculus**: studies accumulation, areas, and volumes through integrals
    - **Multivariable Calculus**: extends calculus to functions of several variables, essential for gradients in ML
- **Combinatorics**: the mathematics of counting, arranging, and combining objects
- **Differential Equations**: equations relating functions to their derivatives, used to model change over time
- **Discrete Mathematics**: the study of countable structures such as logic, sets, graphs, and integers
- **Graph Theory**: the study of networks of nodes connected by edges
- **Higher Mathematics**: advanced, proof-based mathematics beyond calculus
- **Linear Algebra**: the mathematics of vectors, matrices, and linear transformations
- **Linear Optimization**: finding the best outcome of a linear objective subject to linear constraints
- **Numerical Analysis**: algorithms for approximating mathematical solutions on computers
    - **RK4 (Fourth-Order Runge-Kutta)**: steps through a differential equation's solution with high accuracy
- **Probability**: the mathematics of uncertainty and how likely events are
    - **Bayes' Theorem**: computes a probability from the reverse conditional probability and a prior
    - **Normal (Gaussian) Distribution**: the bell-shaped distribution defined by a mean and standard deviation
- **Real Analysis**: the rigorous study of real numbers, limits, continuity, and convergence
- **Statistics**: collecting, analyzing, and interpreting data to draw conclusions
    - **Bayesian Statistics**: updating the probability of a hypothesis as new evidence arrives
    - **Correlation**: how strongly two variables move together, from −1 to +1
        - **Multicollinearity**: when input features are highly correlated, making model estimates unstable
    - **Multivariate Analysis**: analyzing several variables at once to understand how they relate
    - **Statistical Inference**: drawing conclusions about a population from a sample
    - **Time Series Analysis**: analyzing data points ordered in time to find trends and forecast values
        - **Autocorrelation**: how strongly a series correlates with its own past values
        - **Exponential Smoothing**: forecasting with a weighted average that favors recent values
        - **Rolling Window**: computing a statistic over a sliding window of recent points, like a moving average
        - **Stationarity**: when a series' mean and variance don't change over time
            - **Differencing**: subtracting consecutive values to remove trend
        - **Time Series Decomposition**: splitting a series into trend, seasonality, and noise
