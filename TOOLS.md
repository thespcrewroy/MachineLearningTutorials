## Big Data
- **Data Lakehouse**
    - **[Databricks](https://docs.databricks.com/)**: unified analytics platform built on Apache Spark, with a free edition
- **Data Warehouse**
    - **[Google BigQuery](https://cloud.google.com/bigquery/docs)**: Google's serverless data warehouse for running SQL analytics at scale
- **Distributed Computing**
    - **[Apache Hadoop](https://hadoop.apache.org/)**: framework for distributed storage and MapReduce processing of big data
        - **[Apache Hive](https://hive.apache.org/)**: SQL-like querying over data stored in Hadoop
    - **[Apache Spark](https://spark.apache.org/docs/latest/)**: fast in-memory engine for large-scale data processing and analytics
- **Distributed Key-Value Store**
    - **[Apache Accumulo](https://accumulo.apache.org/)**: sorted, distributed key-value store for scalable data storage and retrieval
- **Full-Text Search**
    - **[Elasticsearch](https://www.elastic.co/docs)**: distributed search and analytics engine for full-text search, logs, and real-time queries
